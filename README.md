# Modern React App

This project is scaffolded with [Vite](https://vitejs.dev/) + [React](https://react.dev/) + [TypeScript](https://www.typescriptlang.org/).

## Features

- **Vite** for optimized development and production builds.
- **TypeScript** for type safety.
- **Modern CSS** using CSS variables and reset.
- **ESLint** & **Prettier** for code quality.
- **Folder Structure**:
  - `src/components`: Reusable UI components
  - `src/pages`: Route-based pages
  - `src/hooks`: Custom React hooks
  - `src/utils`: Helper functions
  - `src/styles`: Global styles

## Getting Started

1. Install dependencies:

   ```bash
   npm install
   ```

2. Start development server:

   ```bash
   npm run dev
   ```

3. Build for production:
   ```bash
   npm run build
   ```

## Customization

- Update `src/styles` generally (variables are in `src/index.css`).
- Add components in `src/components`.
- Edit `src/App.tsx` as the main entry point.

Happy coding!
